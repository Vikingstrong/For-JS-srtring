# For-JS-srtring

## Почему String можно использовать как объект однако он является примитивом?
В Java Script типы данных делятся на 2 примитивы и объекты. String является примитивом. Однако когда мы используем какие либо методы или вызываем строки по индексу, JS в ручную под капотом превращяет string в **object**. К примеру представим что у нас есть строка str с содержанием Hello World, и мы хотим сделать все буквы строки заглавными используя метод toUpperCase.
```js
let str = "Hello, World!";
let l = str.toUpperCase();

console.log(l); //Выведет все наши буквы большими
```
таким образом когда когда мы используем метод toUpperCase() js вручную превращяет строку в обьект и в нашем случае считает количество всех символов внутри строки.

## Как создать пременую с значением String?
Есть 2 основных варианта которые не сильно отличаются друг от друга. двойные ковычки "" и еденичные ''.

```js
let str1 = "Hello, World!";
let str2 = 'Hello, World!';
```
они не отличаются ничем крме как видом. 
Есть 3 универсальный тип строки в котором можно использовать код, однако его используют в основном для переменых
```js
let sch = "School"
let str = `I go to ${sch}`; // внутри обьектных ковычек с использованием доллара можно писать любой код однако его в основном используют для переменых

console.log(str)// Выведет I go to School

```

## Индексы строк

У каждого элемента внутри string имеется свой индекс который начинается с 0. индексы строки работают так же как и индексы масивов поскольку как мы уже говорили ранее js под капотом превращяет строку с примитива в объект.
```js
let str = "Hello, World!";

console.log(str[0]); //Выведет H поскольку H является 1 буквой и имеет индекс 0
```

# Встроеные методы JS 
## Char At and At
CharAt и at выполняют одну и ту же фукнцию имея лишь небольшое различие. Они показывают букву которая находится на определёном индексе
```js
let s = "hello";

console.log(s.CharAt(2)) // выведет l
```

Так же и работает с at

``` js
console.log(s.at(-1)) // выведет o
```
Метод at() более современый вариант поскольку at() может принимать отрицательные индексы в отличии от charAt(). Это их единственое и основное различие

## Поиск текста внутри строки includes()

includes проверяет есть ли текст внутри строки. includes() может вернуть всего 2 значения true and false. Пример 

``` js
    let s = "hello";
    return s.includes("hello"); //true
```
``` js
    let s = "hello";
    return s.includes("hi"); //false
```

Однако includes очень чуствителен к буквам.

``` js
    let s = "Hello";
    return s.includes("hello"); //false поскольку тексты не совпадают
```
## IndexOf() Поиск индекса по позиции символа
Indexof() предназначен для нахождения индекса по символу строки. Пример:

``` js
    let str = "World"

    console.log(str.indexOf("r")) //Выведет 2 потому что буква r находится на 2 индексе
```
Однако если indexOf() не находит символ выведет -1

``` js
    console.log(str.indexOf("s")) //Вывод -1
```
