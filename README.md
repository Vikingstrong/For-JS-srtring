# For-JS-srtring

## Почему String можно использовать как объект однако он является примитивом?
В Java Script типы данных делятся на 2 примитивы и объекты. String является примитивом. Однако когда мы используем какие либо методы или вызываем строки по индексу, JS в ручную под капотом превращяет string в **object**. К примеру представим что у нас есть строка str с содержанием Hello World, и мы хотим узнать длину строки используя свойство length.
```js
let str = "Hello, World!";
let l = str.length;

console.log(l); //Выведет длину ВСЕЙ строки (13) с учетом всех пробелов и прочих символов
```
таким образом когда когда мы используем свойство length js вручную превращяет строку в обьект и в нашем случае считает количество всех символов внутри строки.

## Как создать пременую с значением String?
Есть 2 основных варианта которые не сильно отличаются друг от друга. двойные ковычки "" и еденичные ''.

```js
let str1 = "Hello, World!";
let str2 = 'Hello, World!';
```
они не отличаются ничем крме как видом. 
Есть 3 универсальный тип строки в котором можно использовать код, однако его используют в основном для переменых
```js
let sch = "School"
let str = `I go to ${sch}`; // внутри обьектных ковычек с использованием доллара можно писать любой код однако его в основном используют для переменых

console.log(str)// Выведет I go to School

```

## Индексы строк

У каждого элемента внутри string имеется свой индекс который начинается с 0. индексы строки работают так же как и индексы масивов поскольку как мы уже говорили ранее js под капотом превращяет строку с примитива в объект.
```js
let str = "Hello, World!";

console.log(str[0]); //Выведет H поскольку H является 1 буквой и имеет индекс 0
```
